## 4. 한국어 검토 환경 배포 절차 (a8cc397 이후 헤드)

```sh
git fetch origin && git worktree add ../life-help-korean-review origin/release/learn-math-prod-korean-review-20261015 && cd ../life-help-korean-review
npm ci && npm run build && npm run check:worker-size && npm run test:learn:bundle
npx wrangler deploy --config wrangler.korean-review.jsonc          # 새 Worker life-help-korean-review (workers.dev)
```
설정 파일의 바인딩(변수): `APP_ENV=staging`, `KOREAN_REVIEW_MODE=1`, `LEARN_SUPABASE_URL`/`EXPECTED_LEARN_SUPABASE_REF` = **스테이징** 프로젝트 `wreebowcbiymodswajwe`(운영 `wstdbymmkrqgtsibhcjz`는 사용 금지), `SERVICE_CORE_*` 동일. 경로·커스텀 도메인 없음.

배포 직후 Worker 시크릿(값은 어디에도 기록하지 말 것; 맥북 기존 스테이징 설정에서 가져옴):
```sh
npx wrangler secret put LEARN_SUPABASE_PUBLISHABLE_KEY --config wrangler.korean-review.jsonc
npx wrangler secret put LEARN_SUPABASE_SECRET_KEY      --config wrangler.korean-review.jsonc
npx wrangler secret put KOREAN_REVIEWER_EMAILS         --config wrangler.korean-review.jsonc   # 쉼표로 구분한 검토자 이메일
```
- 접근 규칙: ① 이 Worker의 환경(`KOREAN_REVIEW_MODE=1` + `APP_ENV=staging|local`) ② 스테이징 Supabase에 **로그인한 검증된(확인된 이메일) 사용자**가 `KOREAN_REVIEWER_EMAILS`에 있거나 `learn_staff_users`에 행이 있을 것. 서버에서 매 요청 판단하며 URL 비밀·클라이언트 플래그는 판단에 쓰이지 않습니다.
- 가입은 닫혀 있습니다(`SIGNUP_ENABLED=false`). 검토자는 **스테이징 Supabase에 이미 있는 계정**으로 로그인합니다. 새 Auth 사용자를 만드는 것은 원격 DB 쓰기이므로 이번 승인에 포함되지 않았습니다(별도 결정 필요).
- 진도·DB 쓰기 없음: 콘솔은 읽기 전용이며 검토 기록은 검토자 브라우저 `localStorage`에만 저장되고 JSON/CSV로 내보냅니다. 기존 DB의 K7~K10 저장 제약(`level_requires_db_upgrade`)은 건드리지 않았습니다.
- 알려진 제한: 로그인 후 자동으로 `/review`로 돌아오지 않습니다(로그인 후 아래 링크로 이동).

스모크:
```sh
node scripts/staging/review-smoke.mjs https://life-help-korean-review.<account>.workers.dev
REVIEW_COOKIE='…' node scripts/staging/review-smoke.mjs https://…       # 검토자 쿠키는 환경 변수로만(출력·기록 금지)
NONREVIEWER_COOKIE='…' node scripts/staging/review-smoke.mjs https://…  # 비검토자는 거부되어야 함
```
복구/제거: 사용자 영향이 없는 별도 Worker입니다. 끄려면 `npx wrangler delete --name life-help-korean-review` (또는 `KOREAN_REVIEW_MODE`를 지우고 재배포하면 콘솔 전체가 404). 운영 Worker·DB에는 영향이 없습니다.

짧은 점검표(레벨마다):
1. 정답이 정확히 하나이고 ✓가 맞는가? 한국어 문장·맞춤법·로마자가 맞는가?
2. 오답 보기가 자연스럽지만 분명히 틀린가? (K9 비즈니스 포함)
3. 힌트가 정답을 알려 주지 않는가? 해설이 맞는가?
4. 번역 줄: `localized`(그 언어), `fallback`(영어 대체), `English source`. 이상한 번역은 `번역`으로 기록.
5. 레벨·스킬·ID가 문항과 맞는가? 중복은 없는가?
6. 문제는 문항마다 *문제 기록*에 남기고 끝나면 JSON/CSV로 내보내기.
