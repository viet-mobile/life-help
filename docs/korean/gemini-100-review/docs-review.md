## (a) 재분류 문서가 실제로 다루는 범위

- 6급 0개라는 결과는 우리와 같지만, "6급이 가장 부족하다"는 문항 수 집계가 없다.

- **추출본으로 뒷받침되지 않는 인용(핵심 결함):**

  2. "자모의 소리를 식별하고 바르게 읽고 쓴다"를 1급 성취기준 직접 인용처럼 씀: 추출본에 없는 문장. 가장 가까운 것은 읽기 1급-5 "발음과 표기가 다를 수 있음을 알고 기초 어휘와 짧은 문장을 바르게 읽을 수 있다"(p.15 앞). 날조된 따옴표 인용.
  3. 4급 "비즈니스 서식 및 보고 표현", 6급 "정책 분석, 전문 법률·행정 담화", 3급 "간접화법과 복합 연결어미 구사"를 총괄목표로 요약: 실제 표 2는 4급 "지시와 보고", 6급 "설득·권고, 전문·학술 담화"까지만. 법률·행정·정책분석 언급은 없음.
  4. K9를 "4급 직장에서의 기본적인 업무에 필요한 발화 및 서식 이해"로 따옴표 인용: 표 2/3의 실제 문구는 "직장에서의 기본적인 업무와 관련된 담화"로 바꿔 쓴 변형 인용. K10 "사회적 소재의 글, 관용 표현 및 문화적 맥락 이해"도 추출본에 없는 문장.
  5. 말하기 표(표 4)를 포함해 쓰기 표(표 6)는 사실상 인용하지 않았다.

## (d) 학습자 지원안 문제점
1. **존재 확인 불가 코드:** `lib/learn/korean-standards.ts` 파일 없음(확인). "런타임 메타데이터 매퍼"는 미구현 제안인데 "방안"처럼 서술.
2. **DDL이 보존 원칙과 충돌:** `learn_courses.standard_grade`에 '3-4급', '4-5급' 같은 범위 문자열을 넣고 K4~6=2급으로 일괄 변환. (i) grade-map과 모순(K4 대부분 1급), (ii) 열 의미를 문자열로 오염, (iii) 044 CHECK는 `grade`만 K1~K10 허용하며 새 열 DDL은 044가 아닌 새 마이그레이션이 필요한데 본문은 044 "운영 적용 완료"를 단정(저장소엔 파일만 있고 배포 상태는 미검증). 사용자 지시 "DB·운영 변경 없음"과도 어긋나므로 실행 금지, 제안만 허용.
3. **번역 수치 미검증 및 내부 불일치:** "14개 언어 완전 번역"인데 나열은 15개(en,ko,vi,ja,zh-Hans,zh-Hant,th,id,uz,mn,ru,es,fr,de,ne). 32개 언어 × 2,604 = 83,328은 산술만 맞고 코드/데이터 근거 없음. "미완성 32개 언어는 코스만, 문제은행 비공개"는 현행 코드에 구현된 정책인지 확인 안 됨.
4. **hoc-tieng-viet-mobile 참조:** 이 저장소에 없는 외부 아키텍처를 "검증된 PWA"라 부르나 근거 코드 없음. 5개 학습 모드(받아쓰기·듣기 등)는 현재 앱 기능으로 존재하는지 확인되지 않은 계획. 우리 현황(말하기 평가 스킬 0, 쓰기 16)과 비교하지 않음.
5. **발음 대조표 근거 약함:** "국립국어원 연구 기반"이라 하나 출처 없음. 일부 오류: 중국어권 "종성 ㄹ 설근음화", 일본어 "어두 유성음화(가방→[gabang])" 등은 단정적이며 검증 불가. 영어권 "어/오·으/우" 혼동은 일반적이나 [ㄷ]종성 설명은 일본어 학습자에 한정한 단정. 문서의 "국적 단정 배제" 원칙과 표 구조(언어권=오류)가 상충.
6. **TTS 속도 매핑**(0.8/1.0/1.2배를 급에 고정)은 설계 제안일 뿐 표준·코드 근거 없음. 브라우저 `speechSynthesis`의 ko-KR 음성 가용성은 기기별로 불균일.
7. 긍정: 모드 복제를 독립 항목으로 세지 않는 집계 원칙, 선택형을 말하기/쓰기로 과장하지 않는다는 원칙은 우리 방침과 일치. K1~K10 코드·문항 ID 유지 선언도 일치(단 위 2번 제외).
