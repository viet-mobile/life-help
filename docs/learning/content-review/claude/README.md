## 가장 중요한 발견 (직접 확인함)

1. **은행 문항 대부분이 같은 문항의 반복입니다.** 영어 4,345문항 중 서로 다른 (학년, 스킬, 지문, 정답)은 **266개(6%)**, 한국어 3,510문항 중 **297개(8%)**입니다. 학년·레벨당 "360문항"의 실체는 약 20~27개 문항에 보기 순서와 오답만 바꾼 것입니다. 문항 수 기준(학년당 400+)은 충족해도 연습 효과와 학년별 평가는 그만큼 없습니다. 한국어 K1~K10은 레벨당 서로 다른 문항이 27~45개입니다.
2. **같은 문항이 관련 없는 스킬에 복제**돼 스킬 이름과 문항 내용이 맞지 않습니다(예: K10의 어휘 문항이 media_headline·sino_four·logic_debate에 동시에 있음).
3. **정답 오류와 비문**: E1 알파벳 "Box"의 정답이 X로 표시, "Seoul for three years" 시제 문항 4개가 모두 비문, 관계사 문항의 정답이 문법에 안 맞음(where/when 뒤에 주어가 없음), 조건문 문항의 정답이 문장과 안 이어짐. 상세는 `01-english-bank-findings.md`.
4. **학년 불일치**: 고등 수준 문항(Hardly 도치, nevertheless, 주제 찾기)이 E2~E5 스킬에 들어 있습니다.
5. **영어 심화 독해 56문항의 정답이 전부 `a`**이고 난이도가 전부 3입니다. 지문은 30~39단어 2문장이며 레슨당 7문항이 같은 지문을 씁니다. 교육과정 성취기준 코드는 어디에도 없습니다. `03-english-reading-findings.md`.

7. **K6→K7 연결 부족**: 간접화법에 필요한 평서형 어미, 기본 연결어미(-아/어서, -지만, -(으)니까 등), 합쇼체 서술형 -ㅂ/습니다가 K1~K6에 없습니다.
8. **K7~K10 레슨 제목·개념·스킬 제목은 46개 언어 전부 영어 원문 그대로**입니다(72개 필드 × 46, 스킬 36 × 46). 질문 지문·힌트·해설은 번역돼 있습니다.
9. **통합 충돌**: 읽기 전용 시험 병합(`git merge-tree`)에서 `lib/learn/content/bank.ts`, `asset-manifest.json`, `scripts/learn/korean/kit-extra/*.json`이 충돌합니다. Gemini의 `bank.ts`는 정적 문항 목록 형식이고 Claude의 `bank.ts`는 수학 파라미터 은행입니다. 한쪽을 다른 쪽에 덮어쓰면 수학 은행이 사라지니 이름을 나누거나 함께 지원해야 합니다.

## 검사 범위와 표본 수

| 대상 | 범위 | 방법 |
|---|---|---|
| 영어 은행 | 4,345문항 전수(구조) + 서로 다른 항목 266개 전수(의미) | 스크립트 + 에이전트 3명 |
| 한국어 은행 | 3,510문항 전수(구조) + 서로 다른 항목 297개 전수(의미) | 스크립트 + 에이전트 3명 |
| 영어 심화 독해 | 56문항 전수, 4과목 8레슨 | 에이전트 1명, 정답 분포는 직접 확인 |
| K7~K10 | 선수학습 표 36행 전수, 진행 표 K5~K10, 문항 80개 층화 표본(모든 레슨 포함), 정답 키 전수 대조 | 에이전트 1명, K10 난이도·참/거짓·빈 해설은 직접 확인 |

구조 검사는 전체 문항에서 ID 중복, 보기 4개, 정답 id 존재, 보기 텍스트 중복, 힌트 2개, 빈 해설, 템플릿 누출, 정답 위치 분포를 봤고 위반은 0건이었습니다(영어 정답 위치 a 1,085 / b 1,090 / c 1,085 / d 1,085). 문제는 형식이 아니라 **내용의 다양성과 정확성**입니다. 서로 다른 항목 기준 전수 검토라서 표본 추출은 없습니다. 에이전트는 반복 항목을 한 번만 보고하는 경우와 복제본마다 보고하는 경우가 섞여 건수가 중복될 수 있습니다.
