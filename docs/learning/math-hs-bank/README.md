## 검증
1. **독립 계산**: 모든 행의 정답을 생성기와 코드가 다른 Python/sympy 검증기(`scripts/learn/bank/hs/verify/*.py`)가 다시 계산해 일치를 확인(6,491 / 6,491, 실패 0). 검증기는 프롬프트가 의존하는 조건(유일성, 정의역, 종결 소수 등)을 단언하고, 해설에 표시된 중간값도 상당수 재계산합니다. `verification.json`이 검증한 파일의 sha256을 기록하고, 테스트가 현재 파일과 일치함을 확인합니다.
2. **독립 AI 검토**(작성자와 분리된 검토자 7명, 과목 묶음별): 총 209개 지적(blocker 5, major 46, minor 158) → `review/*.json`. 정답이 틀리거나 둘인 문항은 발견되지 않았으나, 분수·소수 표기 약속(결과가 순환소수인데 소수 입력을 허용), 누락 조건, 교육과정 범위 밖 내용, 과대 표기된 성취기준·증거 라벨, 한국어 조사, 오해 소지 힌트·해설이 발견되어 수정 에이전트가 반영했고 검증기를 다시 실행했습니다. 분수 표기는 빌더가 일괄 처리합니다(순환소수가 나오는 템플릿 82개는 "기약분수로 쓰세요"를 요구하고 해설에 분수를 표시).
3. 자동 검사 통과와 AI 검토는 **교사·전문가 검토가 아닙니다.** 검토 결과의 일부 minor 항목은 의도적으로 남겼습니다(각 수정 보고 참고).
