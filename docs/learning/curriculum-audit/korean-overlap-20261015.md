# 한국어 은행 겹침 확인 — 2026-10-15

기준: main의 `7aa2d4f` 한국어 format-2 은행과 Gemini 보존본 `da97f127ee5c8ee6f1e040711ba3ddbd29ac29c7`의 format-1 은행. 두 파일을 그대로 합산하지 않는다.

- 현재 은행: 11,184 ID, 고유 학습 항목 2,197개 + 음절 항목 210개. 영어·한국어 키트로 펼친 각 11,184개에서 완전히 같은 문항은 없었다. 형식 변형과 내용의 독립성은 별도 판단이다.
- Gemini 기존 은행: 3,510 ID이지만 스킬·ID·보기 순서를 제외한 내용 조합은 33개다.
- 문항 유형, 지문, 한국어 대상/음성, 정답 내용, 정렬된 보기 내용을 NFC·공백 정규화하여 비교하면 두 은행 간 완전 일치는 0개다. 현재 은행은 영어·한국어 키트 양쪽으로 비교했다.
- 기존 은행의 한국어 정답 문자열 중 현재 항목의 한국어 대상과 같은 것은 5개다. 이 값은 의미 중복 검사를 대신하지 않는다.

**완전 일치 0개는 새로 배울 내용이라는 뜻이 아니다.** 제시 언어·질문 형식·오답이 달라 의미가 같은 항목도 다르게 집계될 수 있다. 기존 은행에는 미해결 정답·스킬 문제도 있으므로 33개조차 목표 보충 수량으로 인정하지 않는다. 현재 은행 기준으로 최소 816문항을 새로 보충하고, 읽기·대화 부족을 우선한다.
