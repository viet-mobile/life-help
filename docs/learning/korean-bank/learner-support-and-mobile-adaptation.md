# 학습자 언어·발음 지원 및 모바일 UI 학습 모드 적용안

**참조 표준**: 국립국어원 표준 발음법, 언어권별 한국어 대조 분석 연구, `hoc-tieng-viet-mobile` 아키텍처 명세  
**원칙**: 목표 한국어 표현은 원형 보존, 메타 정보(지시문·해설·힌트·뜻)는 학습자 모국어 제공. 국적 단정을 배제하고 학습자 오답 패턴 기반 적응형 피드백 제공. 동일 항목의 다중 학습 모드는 독립 항목 수와 엄격히 구분.

---

## 1. 학습자 다국어 지원 원칙 및 현황

### 1.1 이원화 제공 원칙
1. **한국어 원형 보존 대상 (Target Content)**:
   - 한국어 발음 음가, 철자, 단어, 문장, 지문, 어순 배열 타일.
   - 정답 선택지 중 한국어 형태 자체를 식별하는 보기(toko, cloze, choose, order 등).
2. **학습자 언어 번역 대상 (Presentation Kit)**:
   - 문제 지시문(prompt template), 단계별 힌트(hints), 문법 및 문화 해설(explanation).
   - 한국어 단어/표현의 의미를 묻는 보기(meaning, tf).

### 1.2 현행 번역 현황 및 누락분 감사
- **완전 번역 완료 (14개 언어)**: `en` (기준 정본), `ko`, `vi`, `ja`, `zh-Hans`, `zh-Hant`, `th`, `id`, `uz`, `mn`, `ru`, `es`, `fr`, `de`, `ne` (총 2,644개 텍스트 전수 번역).
- **최소 번역 상태 (32개 언어)**: `am`, `ar`, `arz`, `bn`, `da`, `el`, `fa`, `gu`, `he`, `hi`, `it`, `kk`, `km`, `kn`, `ml`, `mr`, `my`, `nl`, `no`, `pa`, `pl`, `pt`, `sg`, `si`, `sv`, `sw`, `ta`, `te`, `tet`, `tr`, `uk`, `ur`.
  - 언어당 미번역 텍스트: 2,604개 (의미 g: 2,157개, 상황 s: 209개, 문법 노트 n: 238개).
  - 전체 누락 텍스트: 83,328개.
- **공개 방침**: 32개 미완성 언어에 대해 문제은행을 임의로 열지 않으며(코스만 제한 제공), 번역이 완비된 14개 언어에 한하여 문제은행을 완전 노출합니다. 미번역분을 완료로 표시하지 않습니다.

## 2. 언어권별 대조 발음 분석 및 적응형 마이크로 피드백 설계

국적만을 근거로 학습자의 발음 오류를 단정하지 않으며, **학습자가 실제 틀린 오답 보기 및 진도 단계에 맞춰 맞춤형 교정 힌트를 제공**합니다.

| 언어권 | 주요 음운 대조 특성 (국립국어원 연구 기반) | 취약 오답 패턴 | 적응형 교정 피드백 (Micro-Feedback) |
|---|---|---|---|
| **베트남어권 (vi)** | - 평음-경음-격음(ㄱ-ㄲ-ㅋ, ㄷ-ㄸ-ㅌ, ㅂ-ㅃ-ㅍ) 삼지적 대립 부재<br>- 종성 파열음의 비파열(미파화) 경향<br>- 음절 성조 간섭 | '달(달)'과 '딸(경음)', '탈(격음)'의 혼동 | *"한국어는 숨의 세기와 목의 긴장도로 뜻이 달라집니다. '달'은 편안하게, '딸'은 목에 힘을 주고 단단하게, '탈'은 숨을 강하게 내뱉으세요."* |
| **중국어권 (zh)** | - 무기음-유기음(b/p, d/t, g/k)의 2중 대립에 익숙<br>- 종성 [ㄹ] 유음 발음의 설근음화 경향 | '불'과 '뿔', '물'과 '문'의 종성 혼동 | *"한국어 'ㄹ' 받침은 혀끝을 윗잇몸 뒤에 가볍게 대고 소리를 냅니다. 혀를 뒤로 말지 마세요."* |
| **영어권 (en)** | - 유성음/무성음(Voicing) 중심 인지<br>- 강세 박자 언어(Stress-timed) 특성으로 모음 약화 경향 | '어'와 '오', '으'와 '우'의 모음 변별 혼동 | *"'어'는 입을 편하게 벌리고 턱을 내리며, '오'는 입술을 동그랗게 모아야 합니다."* |
| **일본어권 (ja)** | - 어두 자음의 유성음화(가방->[gabang])<br>- 받침 종성 7개 자음 체계의 음절화(모음 삽입) | '옷[옫]' 뒤에 모음 '으'를 덧붙여 발음하는 오류 | *"받침 'ㅅ'은 음절 끝에서 모음을 붙이지 않고 혀를 윗잇몸에 붙인 채 숨을 멈추어 [ㄷ]으로 끝맺습니다."* |

## 3. `hoc-tieng-viet-mobile` 기반 모바일 UI 및 학습 모드 적용안

`hoc-tieng-viet-mobile`의 검증된 PWA 및 학습 엔진 아키텍처를 LIFE.HELP 한국어 학습에 적용합니다.

### 3.1 Web Speech API 기반 한국어 TTS 엔진 설정
- **합성 인터페이스**: 브라우저 내장 `window.speechSynthesis` 및 `SpeechSynthesisUtterance`.
- **한국어 음성 선택**: `voice.lang === "ko-KR"` 필터링. 브라우저/OS별 최적 음성(Google 한국어, Apple Yuna 등) 기본 지정.
- **속도 조절 (Rate Control)**:
  - `0.8x (느리게)`: 1~2급 음소 식별, 받침 발음, 구개음화 학습용.
  - `1.0x (보통)`: 3~4급 일상 대화 및 문장 독해 표준 속도.
  - `1.2x (빠르게)`: 4~5급 비즈니스 통화, 뉴스 미디어 실전 청취용.

### 3.2 단일 학습 항목(Item) 기반 5대 학습 모드 구현
하나의 독립 학습 항목(예: "식당에서 밥을 먹어요")을 5가지 학습 모드로 다면적 훈련합니다.

1. **플래시카드 (Flashcard Mode)**:
   - 앞면: 한국어 원문 + 원클릭 발음 듣기 버튼 + 발음 표기(초급에 한함).
   - 뒷면: 학습자 모국어 뜻풀이 + 핵심 문법 포인트 및 예문.
2. **선택형 인지 (Multiple Choice Mode)**:
   - 한국어 목표 어휘/표현의 뜻 고르기(meaning) 및 문맥 완성형 보기 고르기(toko).
3. **상황 듣기 (Listening Comprehension Mode)**:
   - 텍스트를 숨긴 채 한국어 오디오를 재생하고, 들은 내용에 부합하는 상황이나 문장을 고르는 청취 인지 훈련.
4. **어순 배열 (Sentence Builder Tile Mode)**:
   - 섞인 한국어 단어/어절 타일을 올바른 문법 어순(SOV)으로 드래그하거나 터치하여 문장을 완성.
5. **받아쓰기 (Dictation Mode)**:
   - 자연스러운 속도의 한국어 발화를 듣고 핵심 조사나 낱말, 문장을 직접 타이핑하여 철자와 음운 변동을 체득.

### 3.3 집계 독립성 원칙 (엄격한 품질 보증)
- 위 5가지 학습 모드는 동일한 학습 항목의 **표현 방식(Format Variants)**일 뿐입니다.
- **감사 및 보고 기준**: 1개의 문장을 5가지 모드로 학습하더라도 **"독립 학습 항목 수는 1개"**로 엄격히 계량하며, 문제은행 수량 12,000개 목표는 단순 모드 복제가 아닌 실질적인 문항 다양성에 기반하여 산정합니다.
- 선택형 인지 문항을 실제 말하기나 쓰기 수행 평가로 과장하여 보고하지 않습니다.
