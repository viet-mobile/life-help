# 2022 개정 교육과정 성취기준과 현재 학습 콘텐츠의 대응표

작성 근거: 운영자가 제공한 성취기준 원문(초 1~2, 3~4, 5~6학년군, 중1, 중2, 중3 수학). 고등학교(공통수학1·2, 대수, 미적분Ⅰ·Ⅱ,
확률과 통계, 기하)는 성취기준 원문을 받은 뒤 같은 방식으로 추가합니다. 학기 구분은 성취기준에 없고(학년군·학년 단위) 교과서 단원
순서를 따릅니다(`lib/learn/content/semesters.ts`). 표기: ● 충분히 다룸 · ◐ 일부만 다룸 · ○ 아직 없음.

현재 구성: 학년마다 기존 4~5개 레슨 + 새 "도형" 레슨 2개(그림이 있는 문제 14개씩).
