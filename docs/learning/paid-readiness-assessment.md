# 유료·글로벌 서비스 수준의 콘텐츠 양과 질 평가 (기준 커밋 38e559c)

결론: **현재 콘텐츠는 유료 정식 서비스로 부족합니다.** 구조(채점·진도·다국어·접근 통제)는 갖춰졌지만 학습량과 공식 교육과정 충족도가 체험판 수준입니다. 수치는 커밋된 콘텐츠에서 직접 센 값이고, 전부 사람(교사·원어민) 검토 전의 자동 검토 기준입니다.

## 1. 양

| 과목 | 레슨 | 문항 | 학년군당 문항 | 학년군당 예상 풀이 시간(문항의 expectedSeconds 합) |
|---|---:|---:|---|---|
| 수학 | 119 | 1,078 | 66~103 | 약 53~88분 |
| 영어 | 64 | 628 | 37~65 | 약 20~49분 |
| 국어(한국어 학습) | 58 | 418 | 65~79 | 약 32~40분 |

- 학년군당 약 1시간 분량입니다. 한 학년 한 과목을 1년 동안 쓰는 유료 학습 서비스의 일반적인 분량(수백 문항, 수 시간 이상)에 한참 못 미칩니다. 학습자가 며칠이면 모든 문항을 소진합니다.
- 반복 연습용 변형 문항은 전체의 약 1/3(수학 366, 영어 213, 국어 116)이고 문항 가족(family)당 평균 4~7개입니다. 같은 구조의 문제가 반복되므로 실제 서로 다른 개념 수는 더 적습니다.

## 2. 공식 교육과정 충족도 (`docs/learning/curriculum-2022-coverage.md`, 자동 검토)

| 과목 | 성취기준 | covered | partial | gap |
|---|---:|---:|---:|---:|
| 수학 | 435 | 64 (15%) | 201 (46%) | 170 (39%) |
| 영어 | 270 | 35 (13%) | 57 (21%) | 178 (66%) |

- 영어 gap의 대부분은 듣기·말하기·쓰기·태도 기준입니다. 현재 문항 형식(객관식 80%, 참거짓, 짧은 입력)으로는 충족을 입증할 수 없어 콘텐츠 추가만으로는 줄지 않고 **문항 형식(듣기 문제, 음성 응답, 쓰기 채점)이 필요**합니다.
- 수학은 문항의 83%가 숫자 답 입력입니다. 계산 기능은 잘 다루지만 설명·추론·그래프 해석·서술형 기준은 대부분 partial입니다.
- 국어(한국어 학습)는 공식 성취기준(한국어 표준 교육과정 2020)과의 매핑을 별도로 작성하지 않았습니다.

## 3. 질

- 장점: 모든 문항에 힌트 2개 이상과 해설이 있고, 정답 키는 서버 판정입니다. 번역은 구조 검사(자리표시자·수식) 기계 검증을 통과했습니다.
- 한계:
  1. 교사·원어민 검토가 없습니다. 특히 저자원 언어 8종과 새 번역 전체.
  2. 해설이 대체로 한 문장입니다. 풀이 과정, 오개념별 피드백, 단계별 안내가 부족합니다.
  3. 난도 곡선과 학습 순서의 교육적 타당성은 교사 검토 전입니다(학기 배치는 사이트의 편성 판단).
  4. 영어는 E1·E2가 공식 교육과정 밖의 확장 콘텐츠이고 중등 M1이 4레슨뿐입니다.
  5. 국어 코스는 K1~K6까지이며 상위 단계가 없습니다.

## 4. 유료 서비스 최소 기준(제안 — 승인 필요)

| 항목 | 제안 기준 |
|---|---|
| 학년군·과목당 서로 다른 문항 | 400개 이상(약 6~8시간), 그중 40% 이상은 새로운 개념·형식 |
| 공식 성취기준 | covered 60% 이상, gap 10% 이하(영어는 듣기·쓰기 형식 도입 전제) |
| 문항 형식 | 수학: 서술·그래프·도형 포함 / 영어: 듣기·받아쓰기·문장 쓰기(채점 방식 결정 필요) / 국어: 읽기·듣기·쓰기 |
| 검토 | 과목·학년별 교사 1인 이상, 언어별 원어민 1인 이상(전체 언어가 어려우면 출시 언어를 한정) |
| 해설 | 풀이 단계가 있는 해설, 대표 오답 피드백 |
| 측정 | 문항 정답률·소요 시간 데이터로 난도 보정(베타 이후) |

## 5. 확장 방식과 비용

- **수학(절차형)**: 숫자만 바꾸는 파라미터화 문항 은행이 효율적입니다. 문장 틀(템플릿)만 45개 언어로 번역하고 숫자 인스턴스는 언어와 무관하므로, 현재처럼 문항마다 번역을 저장하면 용량(이미 콘텐츠 자산 41 MiB)과 번역량이 선형으로 늘어나 비현실적입니다. **템플릿 + 서버 생성 인스턴스(시드 고정)** 구조가 필요합니다. 정답은 서버가 계산하므로 채점 구조는 유지됩니다.
- **영어·국어(언어 학습)**: 영어 문장·어휘는 번역이 필요 없고 지시문만 템플릿으로 번역하므로 같은 방식이 통합니다. 듣기·말하기·쓰기는 음성 합성/인식, 쓰기 채점의 제품 결정과 외부 서비스·개인정보(미성년자 음성) 검토가 선행되어야 합니다.
- 일정은 콘텐츠 양보다 **검토 인력과 형식 결정**이 좌우합니다. 기계 생성량은 늘릴 수 있어도 교육적 타당성은 사람이 확인해야 합니다.
