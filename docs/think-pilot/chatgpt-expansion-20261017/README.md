# 사고력 과제 추가 저작 · ChatGPT

신규 234개: 수학 198, 영어 24, 한국어 12. 기존 ChatGPT 9개와 Claude 과제는 이 수에 포함하지 않는다. 117개 배정 칸마다 신규 2개이며 `ALLOCATION.md`에 전체 목록이 있다. Claude에게 같은 칸마다 10개를 요청하는 지시문은 `CLAUDE-INSTRUCTIONS.md`다.

## 범위와 사용

- 초등 수학 4영역×6학년×2 = 48개, 중학 5영역×3학년×2 = 30개.
- 고교 공통 수학 7분야×3학년 배정×2 = 42개, 기본수학1·2×3학년 배정×2 = 12개.
- 고교 선택 11과목×3학년 배정×2 = 66개. 합계 수학 198개.
- 영어 E1~E6/M1~M3/H1~H3×2 = 24개. E1~E2는 확장 영역.
- 한국어 공식 1~6급 배정×2 = 12개. 내부 K1~K10과 일괄 대응하지 않는다.
- 고교 학년별 배정은 제작 난도·지원 수준이다. 공식 과목 이수 학년을 지정한 것이 아니다. 문항별 성취기준 적합성과 학년별 선수학습은 별도 검토가 필요하다.

`index.html`은 `tasks.json`을 읽는 정적 검토 화면이다. 로컬 HTTP 서버에서 열어 사용한다. 학년/분야 필터, 첫 판단 고정, 새 정보 공개, 판단 유지/수정, 해설 비교, 검토 의견, 답 내보내기를 지원한다. 자유 서술의 정오·수준을 자동 판정하지 않는다. 입력 답은 브라우저 기기에 저장된다.

## 저작·검증 상태

**전체가 저자 초안이다.** 작성자와 분리된 AI 검토, 교사·원어민·학습자 검토를 전수 수행하지 않았다. 독립 추론 구조 234개 또는 창의력 향상 효과가 입증됐다는 뜻이 아니다. 정규화 지문이 다르다는 검사만으로 내용 중복이 모두 제거됐다고 주장하지 않는다.

- `author.py`: 실제 개별 저작 원문을 묶어 JSON·열람 문서를 생성한다. 숫자/이름 회전으로 늘리는 생성기가 아니다.
- `hints.json`: 234개 과제의 개별 힌트.
- `spacing.json`: 임시 띄어쓰기 도구로 제안받은 공백 전용 보정. 공백 제거 후 글자가 달라지지 않음을 검사했다. 맞춤법·교육 타당성 검증은 아니다.
- `verify.py`: 별도로 열거한 117칸과의 대조, 누락 필드/ID/정규화 지문 중복 확인, 37개 선택 수치 점검. 전체 198개 수학 해설의 독립 검증을 대신하지 않는다.
- 저자 점검에서 상자 수납 문제의 변 길이와 이차식 반례를 수정했다. 수정된 최종 초안에도 추가 결함이 있을 수 있다.
- 수학·영어는 한국어 안내, 한국어 과목은 영어 안내다. 다른 언어 번역은 하지 않았다. 화면의 목록·필터는 한국어다.

## 현재 Claude 세트와의 관계

Claude 최신 BATCH2 문서(43da063)는 분야별 10개 요구를 학년별 10개로 축소했다고 명시한다. 470개를 모두 요청 충족이나 품질 승인으로 보지 않는다. 같은 검토 Worker의 최신 배포를 보존하기 위해 이 세트를 그 Worker에 덮어 배포하지 않았다. 본 앱/운영/DB를 변경하지 않았다.
