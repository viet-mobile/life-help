## "일반 문제 10개당 사고력 1개" 기준과의 대비
일반 문제 수 = 공개 중인 직접 작성 문제 + 문제은행 전개 문제(수학 약 14,300, 영어 약 16,300, 한국어 약 14,200). 필요 수 = 올림(일반 문제 ÷ 10).

| 학년 | 일반 문제 | 필요 | 보유 |
|---|---|---|---|
| E1 / E2 / E3 / E4 / E5 / E6 | 713 / 620 / 498 / 720 / 503 / 696 | 72 / 62 / 50 / 72 / 51 / 70 | 72 / 62 / 50 / 72 / 51 / 70 |
| M1 / M2 / M3 | 674 / 501 / 532 | 68 / 51 / 54 | 68 / 51 / 54 |
| H1 / H2 / H3 | 2,404 / 2,098 / 2,909 | 241 / 210 / 291 | 241 / 210 / 291 |

- **수학은 학년별로 필요 수를 채웠다.** H1~H3은 고교 공통 하위 분야와 선택과목 칸을 합친 수이며, H1~H3은 학교 학년이 아니라 난이도 구분이다(과제마다 가정을 `prerequisites`에 적었다). 하위 분야별 일반 문제 수는 집계하지 않아 학년 안에서 칸에 균등 배분했다.
- **영어(필요 약 1,630 / 보유 120)와 한국어(필요 약 1,420 / 보유 72)는 채우지 못했다.** 영어 문제은행 15,669문항과 한국어 문제은행 약 13,450문항이 공개되어 있어 일반 문제 수가 크다. 이전 보고에서 이 둘을 "충족"이라 한 것은 문제은행을 초안으로 잘못 보고 뺀 오류였다.

## 번역
- 대상: 수학·영어 전부(en, zh-Hans, zh-Hant, ja, vi), 한국어 과목 전부(en은 원문, zh-Hans, zh-Hant, ja, vi, **ko 신규**).
- 기존 470개의 누락(수학 9, 영어 11, 한국어 43 문자열/언어)을 채웠다. 신규 1,106개(792 + 314)도 모든 언어가 채워졌다. `tests/think/translation-pending.json`은 모든 언어에서 비었다.
- 한국어 과목의 한국어 지시문(`lib/think/i18n/ko`, 132과제)을 새로 만들었다. 한국어 학습자는 지시문·힌트·해설을 한국어로 보고, 학습 대상 문장은 그대로다. 이 화면에서는 영어 답을 전제로 한 표면 검사를 끈다(`checksOffFor`).
- **한계:** AI 번역이며 원어민·교사 검토를 받지 않았다. 번체는 간체를 OpenCC로 변환한 것이다. 한국어 번역가별로 "영어로 답하세요"를 "한국어로"로 바꾼 곳과 영어로 둔 곳이 섞여 있다(`x-k-k1-*`, `x-k-k5-01`, `x-k-k5-08`, `x-k-k8-*`). 일본어·베트남어 번역은 한국어 수사를 숫자로 풀거나 소수점 표기를 바꾼 곳이 있어 숫자 일치 경고가 많다(대부분 정상).
- 번역 파이프라인으로 병합하면 수동으로 채운 짧은 문자열이 지워지므로, 병합 뒤에 `i18n-audit.ts --missing-json`으로 확인해 다시 채운다.

## 일반 문제 10개당 사고력 1개 흐름
- 대시보드 사고력 카드가 "일반 문제 10개를 풀어 사고력 도전 N개가 열렸어요"(또는 남은 문제 수)를 6개 언어로 보여 준다(`lib/think/cadence.ts`). 기준은 이 기기에 저장된 풀이 횟수(숙련도의 시도 합)와 사고력 시도 횟수다.
- 진행 상태는 기기 로컬 저장이며 서버에 저장하지 않는다. 사고력 과제를 강제하지 않고, 학습자의 학년·사이트로 목록을 거른다.
