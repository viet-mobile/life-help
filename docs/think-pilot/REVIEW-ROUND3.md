# 사고력 과제 전수 독립 검토 기록 (1~3차) · 2026-10-19

**모든 검토는 AI 검토자(작성자·수정자와 다른 인스턴스)가 수행했다. 교사 검토도, 원어민 검토도, 실제 학습자 평가도 아니다.** 통과는 "정답을 숨기고 풀게 한 뒤 키·채점기와 비교했을 때 알려진 결함이 없었다"는 뜻일 뿐, 교육적 효과나 타당성을 입증하지 않는다.

## 방법
정답·모범 답안·채점 기준을 제거한 blind 파일을 검토자가 학생으로서 먼저 풀고(1단계 답안 저장), 그 뒤에 키를 열어 과제마다 5문항(Q1 정답 노출, Q2 복수 정답·채점 오류, Q3 수준 적합, Q4 오답·힌트, Q5 전이·중복)을 판정했다. 서술형 `checks`(정규식)는 실제 엔진(`lib/think/check.ts`)으로 검토자가 만든 유효 답과 오답에 돌려 거짓 거부·거짓 통과를 측정했다. 수정은 별도 에이전트가 하고, 수정본은 `scripts/think/validate-file.ts`로 구조 검증한 뒤 다른 검토자가 다시 blind로 검토했다.

## 최종 상태 (1,548개 + 시범 36 포함, 제거 28)
- 최신 본문이 독립 blind 검토를 통과한 과제: **1,452개** → `status: "reviewed-ai"`.
- **마지막 수정 뒤 재검토를 받지 못한 과제 60개** → `status: "draft"` (3차에서 수정 필요로 판정되어 한 번 더 고쳤으나, 4차 검토는 하지 않았다. 구조 검증과 검토자가 제시한 거짓 거부·통과 사례의 재실행만 거쳤다).
- 제거: 28개(중복). 총 과제 수 1,576 → 1,548.
- 기존 시범 36개는 1·2차 검토 기록(`review-round1/`, `review-round2/`) 그대로 `reviewed-ai`.

## 남은 한계
- 서술형 채점은 여전히 표면 검사다. 글의 질·추론 전체는 판정하지 않으며 "내 답도 타당해요" 표시와 자기 점검이 남아 있다.
- `reviewed-ai` 과제에도 "소거법으로 일부 풀림", "정규식이 드문 표현을 거부" 같은 경미한 우려가 남아 있을 수 있다(`concern`).
- 번역은 AI 번역이며 원어민·교사 검토 전이다. 6개 학습 언어(ko, en, zh-Hans, zh-Hant, ja, vi)만 지원한다.
- 영어·한국어 과제는 학년·등급당 10~14개로 수학(50~229개)보다 적다. 부족분 산출은 `docs/think-pilot/`의 분포 표를 참고하고 보충은 별도 작업이다.
