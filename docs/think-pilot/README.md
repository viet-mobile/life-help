# 사고력 시범 과제 (Thinking-task pilot)

브랜치 `claude/thinking-pilot-20261017` (출시 후보 `7706129` 위, **출시 후보·운영 콘텐츠와 분리**). 기존 문항은 삭제·교체하지 않는다. 검토 화면은 `/think-pilot`(noindex, 로그인·계정 데이터 없음, 메모는 이 기기 localStorage에만 저장).

## 목표 전환
수량 확충(반복 계산·암기·뜻 고르기)이 아니라, 학생이 **추론 · 비교/평가 · 오류 수정 · 반례/성립 조건 · 정보 충분성 판단 · 제약 속 다중 해법 · 판단 수정** 중 하나 이상을 실제로 하는 과제를 설계한다. 긴 지문·낯선 어휘·숫자/이름 치환·보기 순서 변경은 사고력으로 치지 않는다. 기초 연습은 가치가 있으나 이 과제들과 구분한다(`differsFromPlain` 필드).

## 구현된 형식 (시제품, 실제로 풀 수 있음)
| 형식 | 화면 요소 | 자동으로 확인하는 것 | 사람/자기 점검으로 남기는 것 |
|---|---|---|---|
| 판단 → 근거 선택 → 설명 (`choose` → `choose(multi)` → `write`) | 단일/복수 선택, 서술 | 선택이 키·허용된 대안과 일치하는지, 선택이 보여 주는 생각(`reveals`) | 설명의 질 |
| 오류 위치 찾기 → 고쳐 보기 (`pickLine` → `write`/`build`) | 줄 선택 | 오류 줄 위치 | 고친 서술의 질 |
| 여러 해법 만들기 → 조건으로 검증 (`build`) | 숫자 입력 행 추가 | 모든 제약 충족·서로 다른 예 개수(안전한 식 언어, eval 없음) | 왜 그런지 설명 |
| 필요한 정보/질문 선택 (`choose` multi) | 복수 선택 | 충분/불충분 판단과 필요한 질문 집합 | 대안 질문의 타당성 |
| 단계적 공개 → 예측 수정 (`reveal`) | 정보가 단계적으로 열리고 매번 예측 | 각 단계에서 합리적인 예측 집합(여러 개 허용), 예측 변경 횟수 | 수정의 이유 |
| 같은 뜻을 다른 독자·관계·목적으로 (`write`) | 서술 | 표면 특징(정규식: 존대·완곡 표지·필수 정보 포함 등) | 적절성·자연스러움 |
| 학생이 문제/반례를 직접 만들기 (`build`, `write`) | 숫자 입력·서술 | 반례가 조건을 만족하는지, 문장 조건의 표면 특징 | 만든 문제의 가치·명확성 |

공통 화면 요소: 단계별 힌트(관찰/비교/검증할 다음 행동), 능숙한 학생을 위한 **스캐폴드 단계 건너뛰기**(반복 입력 방지), 틀린 뒤 다시 도전, **"내 답도 맞다고 생각해요" 이의 제기**(메모 JSON 내보내기), 검토자 보기(정답 표시), 마무리 화면(자동 vs 사람 검토 구분, 루브릭, 대안 답·판단 어려운 사례, 언어·문화·접근성 주의).

## 새 구현이 필요한 형식 (제안, 시제품 범위 밖)
- 그림/그래프/도형을 직접 조작해 답을 만드는 과제(수학 시각 도구, 드래그 편집) — 현재는 텍스트 표·설명만.
- 교정 편집기(학생이 문장 안에서 직접 고치고 차이 표시), 대화 시뮬레이터(상대 응답이 학생 발화에 따라 분기).
- 학생이 만든 문제를 다른 학생이 풀어 보는 동료 평가·교사 대시보드.
- 음성 말하기 과제(채점은 사람 또는 별도 검증 필요).
- 생성형 AI 피드백 보조: 확정 판정이 아니라 **불확실성 표시 + 재도전 + 이의 제기**를 붙인 제안으로만(미구현, 안전 검토 선행).

## 채점·피드백 정책
- 정오를 **자동으로 확정할 수 있는 것**: 선택지 키, 오류 줄, 수치 제약 충족, 표에서 도출되는 값. 이는 "자동으로 확인됨"으로 표시한다.
- **사람의 검토가 필요한 것**: 설명·서술·번역·말투의 적절성, 만든 문제의 가치. 표면 특징 검사는 "겉모습만 확인"으로 표시하고 정오 판정으로 쓰지 않는다. 학생에게는 모범 답안 여러 개와 자기 점검 항목을 준다.
- 정답이 여러 개이거나 해석이 갈리면 `acceptable`/`alternatives`/`hardCases`에 기록하고 하나만 인정하지 않는다.
- 생성형 AI의 평가는 정오 판정으로 쓰지 않는다. 이 시제품은 AI 채점을 쓰지 않는다.
- 힌트는 정답이 아니라 다음 행동을 안내한다.
