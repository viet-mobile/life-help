# 시범 과제 독립 검토 기록

**모든 검토는 AI 검토자(작성자와 다른 인스턴스)가 수행했다. 교사 검토도, 실제 학습자 평가도 아니다.** 따라서 "창의력·사고력 향상 효과"는 입증되지 않았다. 아래는 과제 설계의 결함을 찾기 위한 품질 점검일 뿐이다.

## 방법
1. 정답·모범 답안·채점 기준을 제거한 *blind* 파일을 검토자에게 주고, 학생이 되어 모든 단계를 직접 풀게 한 뒤(1단계 답안 저장: `phase1`), 정답 파일을 열어 비교했다.
2. 과제마다 5문항을 판정했다: Q1 추론 없이 보기 단서만으로 풀리지 않는가 / Q2 여러 정답·해석 중 하나만 인정하지 않는가(검토자가 직접 만든 학생 답을 실제 채점기에 넣어 거짓 거부·거짓 통과 측정) / Q3 읽기 부담·배경지식이 사고를 가리지 않는가 / Q4 오답이 사고를 드러내고 힌트가 행동 안내인가 / Q5 다른 상황에 적용 가능한 아이디어인가.
3. 1차 검토 → 작성자 수정 → **다른** 검토자의 2차 검토 → 작성자 수정. 2차 수정 뒤의 최종 상태는 **다시 검토되지 않았다**(기계 검사 + 브라우저 전수 풀이만 수행).

## 결과 (문항 판정 수: 12과제 × 5문항 = 60)
| | 1차 defect / concern | 2차 defect / concern |
|---|---|---|
| 수학 | 8 / 25 | 2 / 26 |
| 영어 | 4 / 30 | 3 / 29 |
| 한국어 | 8 / 24 | 2 (+ 해설 오류 1) / 27 |
원자료: `review-round1/`, `review-round2/` (JSON, 과제별 Q1–Q5 판정과 근거).

1차에서 발견되어 고친 대표 결함: 정답이 가장 긴/유일하게 완곡한 선택지(길이·형식 단서), 정답 단서가 되는 제목·힌트·선수학습, 거짓 통과(정규식이 "비싸"의 "싸", "불가능"의 "가능", "example"의 "exam"에 반응), 거짓 거부(타당한 표현 변형), 순열을 서로 다른 예로 세는 문제, 오류 위치 해설의 줄 번호가 0부터인 문제, 복수 선택에서 빠뜨린 정답에 진단 메시지가 없는 문제, 정답이 여러 개인데 하나만 인정한 문항, 어색한 한국어와 키 오류(한국어 k-12).
2차에서 발견되어 고친 대표 결함: m-04/k-09/k-07 서술 채점의 거짓 거부, m-09 정답 위치(c,c,c), e-02/e-06 일정 모순이 객관적이지 않음, e-07 단서 누설, k-11 해설 오류, k-12 모호성 설계.

## 남은 한계 (고치지 않았거나 고칠 수 없음)
- 서술형 채점은 **표면 특징** 검사다. 내용의 옳고 그름(예: 학생이 만든 문제의 지표 합이 틀림, 설명이 맞지만 표현이 다름)은 판단하지 못한다 → 화면에 "겉모습만 확인", `humanReview`로 사람에게 남김.
- 일부 선택 단계는 여전히 소거법으로 일부 풀린다(e-08 s1, e-09 s1, k-01·k-05·k-08·k-10·k-11·k-12의 일부). 재설계 필요.
- reveal 과제(k-05, k-10, e-04 등)는 첫 판단을 반드시 뒤집게 하지는 못한다.
- 수학 m-01 수치 허용오차 1e-9, m-03/m-07 일부 선택지의 "균형 잡힌 선택지가 정답" 경향.
- 예상 시간은 검토자 추정과 다를 수 있다(과대/과소). 실제 학습자 관찰로 보정해야 한다.
- 교육과정 연결은 전부 `null`(근거 확인된 성취기준 코드를 확보하지 못함).
- 한국어 과목 지시문은 영어만 제공(다른 학습자 언어는 같은 구조로 추가 가능, 미번역).

3. 그 뒤에야 학습 효과 평가 설계(사전·사후 과제, 대조군)를 논의한다.
