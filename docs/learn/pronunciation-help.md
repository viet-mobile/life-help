# 발음 도움말 (pronunciation help): 현재 상태

**학습자에게 노출되는 발음 도움말은 아직 없다.** 근거 조사만 끝났고, 조사 결과가 충분하지 않아 출시하지 않았다.

- 조사 원본: `docs/learn/pronunciation-research.json` (8개 주제 × en/zh/ja/vi/ru/mn).
- 한계(조사 에이전트 보고, AI 요약이며 원문 대조 전):
  - 웹 조회 결과가 요약본이라 인용문은 원문과 다시 대조해야 한다. 표준 발음법 조문 원문은 열어 보지 못했다(국립국어원 해설 기사만 확인).
  - 출처가 있는 주제: 삼중 파열음, 받침, 연음, 비음화, 모음 길이(ㅐ/ㅔ). ㄹ은 일부, ㅓ/ㅗ는 러시아어만, ㅡ/ㅜ는 출처 없음.
  - 언어별(L1) 경향 대부분이 ‘출처 없음’이다. 몽골어는 초록 하나뿐이다.
- 출시 원칙(변경 없음): 국적·UI 언어로 학습자의 모국어나 오류를 추정하지 않는다. 팁은 실제 오답(해당 대비를 담은 문항)에서만, 짧게, 학습자가 직접 고른 언어로 보여 준다. 출처 없는 L1 문장은 쓰지 않는다. 기기 TTS 재생은 발음 평가가 아니다.
- 다음 단계: 출처가 있는 5개 주제의 중립 팁(L1 무관)만 먼저 쓰되, 원문 대조 후 번역 키 `pron.*`를 만든다. 나머지는 출처 확보 전까지 보류. 한국어 발음 전문가 검토가 필요하다(AI 검토만으로 완료 처리하지 않음).
