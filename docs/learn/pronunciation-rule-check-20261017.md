# 발음 규칙 도움말: 원문 대조 결과 (2026-10-17)

**EXPERT_REVIEW_REQUIRED = YES.** 한국어 발음 전문가 검토 전에는 완료로 보지 않는다.

- 대조 원문: 국립국어원 어문 규범 `표준 발음법` (https://korean.go.kr/kornorms/regltn/regltnView.do?regltn_code=0002). 도구가 본문을 가공해 돌려주므로(원문 바이트 대조 아님) 인용은 짧은 구절만 쓰고 전문을 복제하지 않았다. 독립된 두 번째 전문 출처(law.go.kr 행정규칙 등)는 열지 못했다 → **원문 대조는 단일 출처, 부분 검증**. 상세: `pronunciation-rule-verification.json`.
- 조문 번호: 제9·13·18·20·23항 **모두 번호는 일치**.
- 발견된 불일치와 조치:
  | 항 | 발견 | 조치 |
  |---|---|---|
  | 제9항 | 팁 문구가 제8항(일곱 대표음)을 말함. 제9항은 ㄲㅋ/ㅅㅆㅈㅊㅌ/ㅍ → [ㄱ][ㄷ][ㅂ] (낱말 끝·자음 앞) | 문구를 제9항 내용으로 교체(ko + 46개 언어 재번역), 예시를 공식 예 `옷[옫]`, `앞[압]`으로 |
  | 제13항 | 모든 받침이 아니라 **홑받침·쌍받침이 모음으로 시작하는 조사·어미·접미사** 앞에서 옮겨 감 | 문구 교체, 코드는 겹받침 제외·제15항 합성어(겉옷, 맛있다 등) 팁 억제 |
  | 제18항 | 일치 (ㄱㄷㅂ계 받침 + ㄴㅁ → [ㅇㄴㅁ], 국물[궁물], 밥물[밤물]) | 변경 없음 (ㄺㄼㄿㅎ 미탐지는 팁 누락일 뿐 오류 아님) |
  | 제20항 | 주 규칙은 맞으나 `다만` 예외(의견란, 임진란, 생산량, 결단력, 공권력, 동원령, 상견례, 횡단로, 이원론, 입원료, 구근류)가 [ㄴㄴ]으로 발음됨 | 예외 낱말은 팁 억제, 문구에 "보통…(예외가 몇 개 있어요)" 추가 |
  | 제23항 | 일치 (예: 국밥[국빱]) | 예시 `닫고[닫꼬]`(공식 예 아님)를 공식 예 `꽂고[꼳꼬]`로 교체 |
- 열지 못한 것: 제8항·제14항·제15항 본문(알려진 지식으로만 확인, 미검증), 제20항 `붙임`(ㅀ·ㄾ + ㄴ) 미구현.
- 유지한 정책: 학습자의 국적·UI 언어로 오류를 추정하지 않음, 팁은 오답/정답 공개 뒤 짧은 낱말에만, 기기 TTS를 발음 평가로 표시하지 않음. 규칙 텍스트는 짧은 설명만 두고 조문 전문을 복제하지 않는다.
