# 발음 안내·TTS 설정·복습 방식 조사 (Gemini 인계)

구현은 Gemini 담당입니다. 이 문서는 (A) 사용자의 요구, (B) 사용자가 준 언어권별 발음 자료, (C) 참고 앱 `hoc-tieng-viet-mobile` 분석, (D) 권장 설계를 모았습니다. 출처가 확인된 것과 확인되지 않은 것을 구분했습니다.

## A. 사용자 요구 (원문 취지)
1. 한국어를 배울 때 학습자의 모국어에 따라 어려운 점이 다르다. 특히 발음에서 중국어권·영어권·일본어권·베트남어권·몽골어권·러시아어권 등 언어권별 유의점이 다르다.
2. **한국어 학습 첫 화면에서 해당 학습자 언어로** 도움이 되는 정보를 준다.
3. 한 번에 너무 많은 음성학 정보를 주지 않고, **진도를 나가면서 꾸준히** 나누어 준다.
4. 온라인 학습은 한국어 발음을 들을 기회가 적으므로, **각자의 기기에 한국어 TTS 음성을 설정하는 방법**을 알려 주고 이를 활용한다. **재생 속도 조절**도 설정할 수 있게 한다.
5. 참고: `hoc-tieng-viet-mobile`의 [발음][설정], [발음][차이] 맨 위(베트남어×한국어).
6. 영어·한국어 학습 방식을 개선하기 위해 `hoc-tieng-viet-mobile`의 [복습] 중 [플래시카드], [보기], [듣기], [어순 배열], [받아쓰기] 방식을 채용한다.
7. 준 가이드라인에 한정하지 말고 언어별로 도움이 되는 정보를 준다.

## B. 사용자가 제공한 언어권별 발음 자료 (**출처 검증 안 됨**)
사용자가 붙여 넣은 글(링크와 수치 포함)을 요약했습니다. **화면에 쓰기 전에 언어교육 자료로 검증해야 하며, 링크는 이 세션에서 열어 보지 않았습니다.** 글 중 "오류율 80~90%" 같은 수치는 인용 논문 확인 전에는 사용하지 마세요.

| 언어권 | 핵심 유의점(사용자 자료의 취지) |
|---|---|
| 중국어 | 평음·경음·격음 3중 구분(기식·긴장도), 받침 폐쇄음(ㄱㄷㅂ)을 터뜨리지 않고 닫기, 한국어에 성조를 넣지 않고 평탄한 억양 |
| 영어 | 음절 박자(강세 박자 영어와 다름), 후설 모음 ㅡ·ㅓ와 ㅗ 구별(입술 둥글기·개구도), 받침 뒤 모음 삽입 방지 |
| 일본어 | 모음 사이 평음 유성음화 때문에 평음·경음 구별 어려움, 받침 뒤 모음(ㅜ·ㅣ) 추가 습관 교정, ㅓ·ㅡ를 ㅗ·ㅜ로 치환 |
| 베트남어 | 평음 ㅂㄷㄱㅈ을 격음처럼 터뜨림, 받침 ㄹ 탈락·ㄴ/ㅇ 대치, 연음 규칙 미적용(끊어 읽기), 의[ɯi]를 이/에로 단순화 |
| 러시아어 | 유성/무성 대립을 평음·경음·격음으로 전환, 비음화·유음화 등 자음동화 낯섦, /w/계 이중모음(ㅘㅝ)을 /v/로 대치, 모음 약화 습관 교정 |
| 태국어 | 조사 사용 혼란, 평·경·격음 혼동과 자음 변동 미적용, 받침 뒤 모음 삽입 |
| 미얀마어 | 받침 ㄹ 발음 탈락·대치, 성조 간섭으로 억양이 어색함, 격음·경음 혼동 |
| 아랍어 | 단모음 부족으로 ㅓ·ㅗ·ㅜ 혼동, 이중모음 단모음화, 문법(어미 변화·어순) 적응 |
| 스페인어 | 모음 사이 평음 유성음화, ㅡ 모음 부재(ㅣ·ㅜ로 대치), 높임법 복잡성 |
| 공통 | 초기 형성이 중요(화석화 방지), 음소만이 아니라 연음·음운 규칙·띄어 읽기 억양을 함께 지도 |

사용자가 붙인 문화권별 개괄(영어권/서유럽, 동아시아, 동남아, 중동, 러시아·중앙아시아)도 같은 성격의 자료입니다: 문법(SOV, 조사, 어미), 사회언어(높임말), 음운(평·경·격음, 받침 ㄹ), 어휘(한자어 비중, 의성·의태어).

**몽골어권**은 사용자가 요구했지만 자료에 내용이 없습니다. 별도 조사가 필요합니다.

## C. 참고 앱 `hoc-tieng-viet-mobile` 분석
저장소: https://github.com/viet-mobile/hoc-tieng-viet-mobile (이 세션에서 읽기 전용으로 clone, 커밋 `8101f91`). 단일 파일 앱(`app_logic.js` 15,316줄, `template.html` 3,763줄)으로 React 컴포넌트가 아닙니다. 이 세션이 읽은 것은 위임한 분석 에이전트의 보고이며, 아래 줄 번호는 그 보고 기준입니다.

### C1. [발음] > [설정]: TTS 안내·음성·속도
- 안내 데이터: `tts_guide_data.py`(92,793 B). `TTS_GUIDE_ORDER = [samsung, android, ios, mac, windows]`, 12개 UI 언어(ko en vi ja zh_cn zh cs de fr hu id pl). 카드마다 `title`, `lead`, `steps[]`, `note`. `**x**`는 굵게, `{langs}`는 음성 언어 목록. `TTS_GUIDE_EXTRA`에 속도·음높이 조절(`tune`), "소리가 안 들려요"(`help`), 홈 화면 추가(`home`).
- 플랫폼별 단계(ko 문구 요약):
  - 삼성: 설정 > 일반 > 글자 읽어주기 > 기본 엔진 삼성 > 음성 데이터 설치. 속도·음높이는 같은 화면 슬라이더. 앱이 다른 엔진을 쓸 수 있으니 Google 엔진에도 설치.
  - 기타 안드로이드: 설정 > 접근성 > 텍스트 음성 변환 출력 > Google 엔진 > 음성 데이터 설치. "말하는 속도"/"피치".
  - iPhone/iPad: 설정 > 손쉬운 사용 > 읽기 및 말하기 > 음성 > 언어별 음성 선택(선택 시 다운로드, Wi-Fi 권장). 속도는 "말하기 속도".
  - Mac: 시스템 설정 > 손쉬운 사용 > 읽기 및 말하기 > 시스템 음성 ⓘ > 언어 선택·다운로드.
  - Windows: 설정 > 시간 & 언어 > 언어 & 지역 > 언어 추가 > 텍스트 음성 변환 설치. 속도는 음성 메뉴의 음성 속도.
  - 도움말: 카카오톡 인앱 브라우저는 음성이 안 나오는 경우가 많으니 Safari 또는 다른 브라우저로 연다(UA에 KAKAOTALK이면 카드를 기본으로 펼침, `ttsHelpCardHtml` app_logic.js 6253).
  - Linux·기타 데스크톱 브라우저는 다루지 않음.
- 렌더링: `ttsGuideMarkup`(6237), `ttsDeviceCardHtml`(6247), `renderPron`(6270).
- 음성 목록: `refreshVoices`(1785)가 `speechSynthesis.getVoices()`에서 장난감 음성(`NOVELTY_VOICE_RE`)을 제외하고 대상 언어로 필터, `onvoiceschanged`와 800/2000/4000 ms 재조회(iOS 지연 대응). `voiceMatchKey`(1781)는 `voiceURI||name||lang`(iOS의 voiceURI 중복 문제).
- **속도**: 앱 안의 속도 슬라이더·프리셋은 **없음**. OS 설정으로 조절하도록 안내하고 코드는 고정 `rate`(베트남어 0.92, 타 언어 0.95)를 씀(`targetSpeechOpts` 2550, `speakStep` 2405). → 이번 요구(앱에서 속도 설정)는 이 앱에 없는 기능이므로 새로 설계해야 합니다.
- 반복 횟수: 1~10, `localStorage` 키 `vn-app-vi-repeat`, 반복 사이 50 ms. Apple Safari는 짧은 한 조각을 쉼표로 이어 한 번에 읽음.
- 저장: 음성 선택은 메모리에만(새로고침 시 초기화). 타깃 언어 사이트만 `tgt-voice-<lang>` 저장.
- 키: `vn-app-vi-repeat`, `vn-app-dialect`, `vn-app-mute-scope`, `vn-app-auto-adv`, `vn-app-srs-v1`, `vn-app-lang`, `tgt-voice-<lang>`.

### C2. [발음] > [차이]
- 데이터: `pronunciation_comparison/*.py`(12개 언어 모듈, 약 500 KB). 모듈마다 `UI = {intro, common, diff}`, `SECTIONS[비교언어] = {title, common, diff}`, 한국어 모듈에는 `CONSONANTS`(자음 주제 카드, 지역별 행, 예시 단어). 텍스트 미니 포맷: `## 제목`, `- 불릿`, 그 외 문단. `__init__.py`의 `parse_blocks`가 `[{h}|{ul}|{p}]`로 변환.
- 예(ko 모듈 `common` 첫 문장): "두 언어 모두 음절이 또렷하게 나뉘고, 음절 끝 자음을 터뜨리지 않고 닫기만 합니다…". `diff`는 A. 베트남어에만 있는 것, B. 한국어에만 있는 것, C. 혼동하기 쉬운 것, D. 체계의 차이.
- 렌더: `pronDiffHtml`(6170–6235). 학습자 언어 섹션이 맨 위·기본 펼침, 나머지는 접힘. 이 앱의 쌍은 항상 "베트남어 × 다른 언어"이며 한국어×영어 같은 독립 쌍은 없음.

### C3. [복습] 5모드
공통: `studyState`(11736), 풀 빌더 `POOL_BUILDERS`(11282), 학습 모드 필요조건 `REVIEW_MODE_NEEDS`(11180). 문항은 무작위 추출이며 영구 저장되는 것은 "간격 복습"뿐입니다(`vn-app-srs-v1`, 1·7·28일). 점수는 세션 한정.
| 모드 | 학습자가 보는 것 | 정오 판정 |
|---|---|---|
| 플래시카드(flash, 12306–12373) | 카드 앞면(목표어 또는 뜻), 눌러서 뒤집기, 이전·다시듣기·섞기·방향 전환·다음 | 채점 없음. 앞면 자동 재생, 뒤집으면 반대 면 낭독 |
| 보기(look, 12563–12603) | 목표어 + 소리 버튼, 뜻 4지선다(오답 3개는 같은 풀에서) | 선택형 |
| 듣기(mcq, 12462–12519) | 소리 버튼만(글자 숨김), 뜻 4지선다, 답한 뒤 글자·뜻 공개 | 선택형 |
| 어순 배열(order, 12651–12933) | 뜻이 문제, 목표어를 공백 단위로 쪼갠 칩을 눌러·끌어 순서대로 | **토큰열 정확 일치**(`join(" ")` 비교, 대소문자·악센트 구분, 대안 순서 허용 없음). 틀리면 정답 표시·낭독 |
| 받아쓰기(type, 12959–13009) | 뜻 + 입력창 + 다시듣기, 목표어 자동 재생 | **`trim` + 공백 접기 + 소문자만**. 악센트·구두점·NFC 정규화 없음 |
- 자동 진행: `AUTO_ADV_SECONDS_OPTS = [0.3, 0.5, 1, 3]`, 오디오가 끝난 뒤 카운트다운 시작(`speakItemThenArm` 11830), 음소거 범위 `vn-app-mute-scope`.
- 찾지 못한 것: 앱 내 속도 슬라이더, 음성 선택 영구 저장, 받아쓰기·어순의 허용 오차.

## D. 권장 설계 (Gemini용 제안)
1. **첫 화면 팁**: 학습자 언어(`locale`)로 한 가지 발음 팁 카드(예: 영어권은 ㅡ·ㅓ, 일본어권은 받아쓰기 아닌 받침, 베트남어권은 평음). 처음엔 한 장만, 접어서 보관.
2. **진도 연동**: 레슨/스킬 ID(예: `k.k1.batchim`, `k.k1.vowels`)에 팁 ID를 연결해 해당 레슨에 도달했을 때 한 번만 보이게 한다. 본 적 있는 팁은 `localStorage`로 기록.
3. **TTS 설정 도움말**: C1의 5개 플랫폼 카드 + "소리 안 남" 카드(KakaoTalk UA 감지)를 47개 언어로. 문구는 AI 번역이므로 "AI 번역" 표시와 확인 필요 표기를 둔다.
4. **속도**: Web Speech API `SpeechSynthesisUtterance.rate`를 앱 설정으로(예: 0.6/0.8/1.0, `localStorage` 키 새로 정의). OS 속도 설정과 이중으로 걸리지 않게 안내. 한국어 TTS 음성이 없는 기기 감지 후 안내(`speechSynthesis.getVoices()`에 `ko-KR`이 없을 때).
5. **복습 UI는 하나만 구현**하고 영어·한국어가 공유한다(요구 조건은 `20261015-claude-handoff-6465388.md` §4).
6. 모든 언어권 팁 문구에는 "AI 작성, 교사·원어민 검토 아님"을 유지한다.
