## 4. 영어에서 한국어와 공통으로 필요한 복습 UI 요구 (중복 구현 금지)
영어 학습에도 `hoc-tieng-viet-mobile`의 [복습] 방식 중 플래시카드·보기·듣기·어순 배열·받아쓰기를 채용하기로 했습니다. Gemini가 한 번만 구현하고 영어가 같은 컴포넌트를 쓰도록, 영어 쪽 입력/검증 조건은 다음과 같습니다.
- 어순 배열: 토큰 비교는 **낱말 텍스트 기준**이어야 합니다(같은 낱말 타일이 두 번 나오는 문장). 이 규칙은 `lib/learn/domain/answers.ts`의 ordering 채점에 이미 반영되어 있습니다(커밋 `519624a`).
- 받아쓰기: 영어는 대소문자·앞뒤 공백·문장 끝 마침표를 무시하고(`normalizeText`), 축약형과 어포스트로피(’ '), 하이픈은 정규화해야 합니다. 철자 오류는 오답으로 두고 힌트로 정답을 보여 줍니다.
- 영어 문항 데이터 예시: `lib/learn/content/bank/english-draft.json`의 `questions[]`(`type: multiple_choice | ordering`, `options[{id,text}]`, `answer`, `hints[2]`, `explanation`). 듣기용 `audioText`는 영어 문장입니다.
- 실제 음성 제시와 문항 일치 확인은 영어 쪽(Claude)이 맡습니다.
