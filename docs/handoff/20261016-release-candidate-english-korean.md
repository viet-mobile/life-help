## 2. 영어 은행 자산 분리
- 은행(12.5 MB JSON)을 Worker 코드에서 제거. `/learn-content/<version>/english-bank/<skillId>.json`(스킬별 63개 파일)과 `index.json`(질문 id→스킬)로 분할. 기존 `ASSETS` 바인딩·`/learn-content/*` worker-first·`proxy.ts` 404 차단·manifest sha256 구조를 재사용(`lib/learn/content/assets.ts`, `scripts/learn/build-content-assets.mjs`, `repository.ts`, `service.ts`).
- 학년 범위: 학습자 학년의 스킬 샤드만 읽음. 질문 하나(힌트 요청): 그 질문의 스킬 샤드만. 접근 계획(`accessPlan`): id 색인만. 샤드 캐시는 6 MiB 상한 LRU.
- manifest에 bank sha, 색인·샤드 sha256·바이트·문항 수를 고정하고 version에 반영. 변조(checksum)·누락·버전 불일치·건수 불일치는 `ContentAssetError`.
- 문항 id·정답·힌트 개수는 불변(id는 내용 해시). 원본 `english-draft.json`은 소스로만 남고 런타임이 import하지 않음(테스트로 고정).
- Worker 5.06 MiB(압축, 예산 7.5 MiB 유지, 이전 7.98).
