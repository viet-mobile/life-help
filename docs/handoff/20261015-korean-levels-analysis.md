# 한국어 K1~K10과 표준 교육과정 6등급: 잠정 분석 (Gemini 인계)

**상태: 잠정.** 코스(레슨 묶음) 단위의 AI 분석입니다. 문항별 검증이 아니며, 교사·원어민 검토도 아닙니다. TOPIK 등급 판정이 아닙니다.

## 1. 근거와 한계
- 사용한 출처: 김정숙·이정희, 「국제 통용 한국어 표준 교육과정의 구성과 내용」, 『새국어생활』 28권 2호(2018), 국립국어원 — https://www.korean.go.kr/nkview/nklife/2018_2/28_0203.pdf (이 세션에서 PDF 텍스트를 추출해 읽음)
- 이 자료가 알려 주는 것: 6등급 체계(초급 1·2, 중급 3·4, 고급 5·6), 범주(주제 17·85항목, 기능 5·52항목, 어휘 10,635개, 문법 336개, 발음 72항목, 텍스트 144항목), 등급별 어휘(1급 735, 2급 1,100, 3급 1,655, 4급 2,200, 5급 2,365, 6급 2,580)와 문법(45, 45, 67, 67, 56, 56) 수, 듣기·말하기의 등급별 내용.
- 요청된 원문 **문화체육관광부고시 제2020-54호(2020.11.27.) 별책1**은 검색으로 찾지 못했고 받지도 못했습니다. 2018 자료의 6등급 체계가 2020 고시와 같은지, 읽기·쓰기 등급별 문장이 같은지는 **원문으로 대조해야 합니다.** 이 문서에서 읽기·쓰기 등급별 내용은 확인하지 못했습니다(듣기·말하기만 읽음).
- 문법 336개 목록과 어휘 10,635개 목록을 받지 못해 항목별 대응은 하지 않았습니다.

## 2. 2018 자료에서 읽은 등급 기준 (듣기·말하기만)
- 1급: 매우 간단한 일상 대화, 정형화된 표현(인사·감사·사과), 자기소개.
- 2급: 일상에서 자주 접하는 상황(식당·가게·영화관), 공공장소(병원·은행·기차역)의 기본 대화.
- 3급: 친숙한 사회적·추상적 주제(직업·사랑·교육)의 간단한 담화, **격식·비격식 구분, 높임말과 반말의 적절한 사용**.
- 4급: 같은 주제를 더 유창하게, **친숙한 업무 상황(간단한 회의, 요약 보고, 업무 지시)**, 요청·보고·지시.
- 5급: 친숙하지 않은 사회적·추상적 주제(정치·경제·과학), **협상·보고·상담**, 학문 영역(강연·토론), 방송 담화.
- 6급: 전문 분야, **설득·권고·주장의 논리 흐름**, 시사 방송(보도·대담·토론)의 인과 분석.

## 3. K1~K10 코스의 잠정 대응
내용은 `lib/learn/content/korean/korean.json`의 코스·레슨 제목과 `lib/learn/content/bank/korean.json`의 스킬 항목 예시에서 확인했습니다.

| 코스 | 내용(요약) | 잠정 대응 | 근거 |
|---|---|---|---|
| K1 | 한글 읽기 | 1급 | 문자·발음, 가장 간단한 표현 |
| K2~K3 | 인사·기본 표현, 나와 가족 | 1급 | 정형화된 표현, 자기소개 |
| K4~K5 | 하루 생활, 지난 일과 계획 | 2급 | 일상 대화, 시제 |
| K6 | 쇼핑·길 묻기·병원·전화·정중한 부탁 | 2급 | 식당·가게·공공장소(병원·은행) |
| K7 | 격식체·반말, 관형절, 연결어미, 능력·의무·허락, 간접화법, -느라고, -을수록, 추측·후회 | 3~4급 | 높임말·반말 구분(3급), 보고 표현(4급) |
| K8 | 높임 어휘, 피동·사동, 하십시오체, 겸양 | 4급 | 격식/비격식 구분, 업무 상황 어투 |
| K9 | 업무 이메일·전화·일정·회의·보고·통계·협상·명함 | 4~5급 | 친숙한 업무 상황(4급), 협상·보고(5급) |
| K10 | 기사 헤드라인·사설, 몸·행동 관용구, 속담, 사자성어, 논리 접속어, 문화 가치 | 5~6급 | 시사·방송 담화, 논리적 흐름(6급) |

- 따라서 사용자 가설("K7~K10은 TOPIK 5~6급 아닌가")은 **절반만** 맞습니다. K7~K10은 초급이 아닌 **중급~고급(3~6급) 내용**이지만 전부 5·6급은 아니고, K7·K8은 3~4급, K9는 4~5급, K10이 5~6급에 가깝습니다. TOPIK(I = 1~2급, II = 3~6급)과의 대응은 이 표준 교육과정 등급 체계를 통한 간접 추정일 뿐, TOPIK 문항·기준과 직접 대조하지 않았습니다.
- 현재 앱의 한국어 문제는 대부분 객관식·배열·참/거짓 형식이라 **읽기·듣기 중심**입니다. 말하기·쓰기는 앱에서 직접 평가하지 않습니다(선택형 인지 문제를 말하기·쓰기 수행으로 표현하면 안 됨).

## 4. Gemini에게 권하는 후속 절차 (구현은 Gemini 담당)
1. 별책1 원문을 받아 6등급 체계와 읽기·쓰기 등급별 목표를 먼저 확인한다.
2. 코스가 아니라 **레슨·스킬 단위**(`k.k7.indirect_state` 등)로 등급과 영역(듣기·말하기·읽기·쓰기)을 태깅한 데이터 파일을 만든다(분류자와 다른 검토자 1회 이상).
3. UI는 내부 ID(K1~K10)를 유지하되, 표시는 등급(초급/중급/고급 + 급)으로 묶는다. 라벨은 47개 언어 번역이 필요하다(`level-labels.test.ts`가 누락을 막는다).
4. 등급 표시 문구에는 "AI 분류, 교사·원어민 검토 아님"을 유지한다.
