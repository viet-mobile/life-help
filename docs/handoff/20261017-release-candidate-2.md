## 4. 영어 힌트 잔여 결함 처리 (완료 아님)
- 2차 전수 독립 검토: 새 힌트 5,859문항 중 223(3.8%) 결함 표시 → **일반 힌트로 되돌림(개선 집계 제외)**; 일반 힌트 9,085문항 중 294(3.2%) 결함 → **중립 힌트로 교체**(`hints/suppress.json`, 결함 제거이지 개선 아님).
- 이후 신규 표본 200(새 힌트 150 + 일반 50): 새 힌트 150 중 정답 노출 13(8.7%)·일반(맥락 없는 stock) 37·반복 2·한국어 1, 일반 힌트 50 중 정답 노출 13(26%). 표본에서 찾은 결함은 제거했다. **전수 검토가 표본보다 훨씬 적게(3~4%) 잡았다 = 검토자 민감도가 낮다.** 남은 정답 노출 결함이 있다고 봐야 한다.
- 권고: 영어 힌트를 운영에 배포하지 말 것. 배포한다면 2번째 힌트를 중립 힌트로 고정(`hints/authored-20261016.json` 비우기 + 중립 교체 확대)하는 안전판을 먼저 결정. 상세: `docs/english-bank/hint-review-20261017.md`.

- 구현: `lib/learn/pron.ts`(표준 발음법 제9·13·18·20·23항에 해당하는 짧은 한국어 낱말만 탐지, 12 테스트), `PronTip`(틀린 답/정답 공개 뒤에만, 규칙당 기기에서 최대 3회, 끄기 버튼), 9개 문구 × 46개 언어 AI 번역.
