# Protocol: author a Korean practice-bank addition packet (supplementary entries)

You write ONE file `scripts/learn/korean/bank/additions/<packet>.json` = `{ "packet": "<packet>", "skills": { "<skillId>": { "notes": { "<noteKey>": "<English grammar note>" }, "entries": [ ... ] } } }`. Entries are appended to the existing pool skill of that id; do NOT edit any other file. The builder derives ids, romanization (Revised Romanization) and the form questions; you only author Korean + English meaning + distractors.

Read first: `scripts/learn/korean/bank/build.mjs` lines 38-135 (exact entry shape and checks), `scripts/learn/korean/bank/pools/<K-level>.json` skills you will extend (existing entries: do NOT repeat a Korean sentence, an English gloss or a situation already there), `lib/learn/content/korean/grade-map.json` (official 1~6급 judgment per skill), and the official criteria extract `/tmp/claude-0/-home-user-life-help/a87be4d3-bc0f-588b-a37f-463c13f095d4/scratchpad/kcurr/standards-tables.txt` (한국어 표준 교육과정 별책1 Tables 2-6; 5 standards per grade for listening/speaking/reading/writing).

## Entry shapes
- sentence: `{ "cat":"sentence", "ko":"…", "g":"natural English meaning", "note":"<key in notes>"?, "cloze":{"blank":"… ____ …","ans":"…","w":["wrong1","wrong2","wrong3"]}, "choose":{"w":["wrong sentence 1","wrong 2","wrong 3"]}, "order":{"parts":["…","…","…"]}, "grade":N, "area":"읽기|듣기|쓰기", "std":"읽기3-2" }`
  `cloze.blank` with ans must rebuild `ko` exactly; w = 3 forms that are WRONG in that slot (grammar/usage), distinct. `choose.w` = 3 near-copies of `ko` that are wrong (one changed slot each). `order.parts` = 2-4 chunks whose space-joined text equals `ko` minus the final . ? ! — use `order` only when the order is natural and not free (Korean word order is flexible: parts must have ONE natural order given the sentence; else omit order). Each sentence should have cloze + choose (and order when valid).
- expr / phrase / word: `{ "cat":"expr", "ko":"…", "g":"…", "s":"situation in English (expr only, optional)", "grade":N, "area":"…", "std":"…" }`
- passage (reading or dialogue): `{ "cat":"passage", "ko":"…text (dialogue as 'A: … B: …')…", "g":"English translation", "read":{"true":"one statement the text supports","false":["wrong 1","wrong 2","wrong 3"]}, "grade":N, "area":"읽기", "std":"읽기6-4" }` — the 3 false statements must be clearly contradicted or unsupported by the text; the true statement must not copy a whole sentence of the text verbatim; one defensible true statement.
`grade` = official grade 1..6 you claim for THIS entry, `area` = the skill area the item mainly practises (듣기 only for items answered by hearing the sentence read aloud by device TTS: do not claim 말하기 or 쓰기 performance; 어순 배열 is reading/grammar practice, not free writing), `std` = the 별책1 standard code (e.g. 읽기6-2: area + grade + number as listed in the table) it practises, quoting the number from the extract. Do not invent codes.

## Rules (an independent reviewer who is not you checks every entry and solves it blind)
1. Natural, correct Korean (spacing, particles 은/는 이/가 을/를, register consistent). Original sentences. Level-true to the grade: **do not assign a higher grade just because a word is hard** — a 5/6급 item needs the TASK of that grade (see the extract: e.g. 5급 formal/professional topics, 6급 expert/academic texts, argument evaluation, implied meaning, formal professional speech), not rare vocabulary.
2. Exactly one defensible answer. Test every distractor: no second acceptable particle/ending/word order. Distractors must be wrong for grammar/meaning, not odd words.
3. No answer leak: do not copy the answer into another entry's blank text, choose options or read statements in your packet; vary the position of what is tested.
4. Every `g` is a distinct natural English meaning (the builder rejects duplicate glosses within a skill and duplicate Korean sentences); `g` must not contain Hangul.
5. Vary topics, speakers, settings, sentence types; no more than 3 entries may share a grammatical frame. Do not write drills that only swap a noun.
6. Safe content: no real persons/brands/politics/religion/violence/romance; no gender/age assumptions for unnamed speakers beyond what the sentence says.
7. Validate: `node scripts/learn/korean/bank/build.mjs --no-write` must print `validated: …` with NO problem lines mentioning your skills (it does not write any file). Fix every reported problem. Never run build.mjs without `--no-write`.
Final reply: file path, entries per skill and per cat, the questions your entries will build (sentence ≈ meaning+toko+listen+tf+cloze+choose+order; passage = 1), the grade claims, and any entry you are unsure about.
